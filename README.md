# Пёс-Компас

Бот в Telegram открывает сайт, на сайте ищут человека для прогулки с собакой. У заявки есть номер и чат.

Нужен Python 3. Токен бота лежит в файле `.env`. Его выдаёт @BotFather. В общий чат токен не отправлять.

## Запуск

В папке проекта:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Сайт откроется на http://127.0.0.1:8080

Во втором окне терминала, из той же папки:

```bash
source venv/bin/activate
python bot.py
```

Админский сайт, третье окно:

```bash
source venv/bin/activate
python admin_app.py
```

Он открывается на http://127.0.0.1:8081 . Пароль лежит в `.env`, строка `ADMIN_PASSWORD`. С публичного сайта ссылки туда нет. В поиске вводится номер заявки, открывается её переписка.

В Telegram напишите боту `/start`. «У меня есть собака» ведёт на форму заявки, «Хочу заработать» — на список. «Откликнуться» открывает чат. Если человек уже нажимал `/start`, бот пишет ему, сколько уведомлений не прочитано.

База создаётся сама, файл `data/kompas.sqlite3`. В сдачу его можно не класть. Файл `.env` тоже не класть.

## Если сайт надо открыть с телефона

Поставить бесплатную программу cloudflared и запустить:

```bash
cloudflared tunnel --url http://127.0.0.1:8080
```

Скопировать адрес `https://....trycloudflare.com` в `.env` в строку `SITE_URL`, перезапустить `python bot.py`. Аккаунт и домен не нужны. Адрес временный.

## Что проверить перед сдачей

1. `/start` присылает текст и кнопку.
2. Новая заявка есть в списке.
3. Фильтр по району оставляет подходящие.
4. На заявку можно откликнуться.
5. В «Мои заявки» тот же ник показывает отклик.
6. «Закрыть» убирает заявку из общего списка.
7. Пустая форма не сохраняется и пишет, какое поле заполнить.
