# Пёс-Компас

Телеграм-бот [@pes_kompas_bot](https://t.me/pes_kompas_bot). Через него ищут человека, который погуляет с собакой.

## Как пользоваться

В Telegram открывают `@pes_kompas_bot` и отправляют `/start`.

- «У меня есть собака» — заявка на прогулку. У заявки появляется номер.
- «Хочу заработать» — список открытых заявок.

Кнопка «Откликнуться» открывает чат этой заявки. Когда приходит новое сообщение, бот пишет, сколько уведомлений не прочитано, и даёт кнопку «Открыть чат». Чтобы напоминание дошло, человек должен один раз написать боту `/start`, а ник в форме должен совпадать с ником в Telegram.

Свои заявки и чат хозяина открываются кнопкой «Мои заявки». Ник тот же, что указан в заявке. Закрытая заявка пропадает из общего списка.

## Переписки

Их смотрят по адресу https://pes-kompas.vercel.app/admin

Пароль: `peskompas`. Его можно сменить строкой `ADMIN_PASSWORD` в файле `.env`.

В боте этой ссылки нет. В поиске вводится номер заявки, открывается её переписка.

## Как это сделано

Бот и страницы написаны на Python. Бот ходит в Telegram через Bot API. Страницы сделаны на Flask. Заявки, отклики и сообщения хранятся в SQLite. Код лежит на GitHub, страницы открываются с Vercel. Токен бота в репозиторий не выкладывал.
