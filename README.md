# Пёс-Компас

Сервис, чтобы найти человека для прогулки с собакой. Бот в Telegram открывает сайт. На сайте оставляют заявку, смотрят список и переписываются в чате заявки.

Сайт: https://pes-kompas.vercel.app

## Как пользоваться

В Telegram боту отправляют `/start`.

- «У меня есть собака» — форма заявки. У заявки появляется номер.
- «Хочу заработать» — список открытых заявок.

Кнопка «Откликнуться» открывает чат этой заявки. Когда приходит новое сообщение, бот пишет, сколько уведомлений не прочитано, и даёт кнопку «Открыть чат». Чтобы напоминание дошло, человек должен один раз написать боту `/start`, а ник в форме должен совпадать с ником в Telegram.

Свои заявки и чат хозяина — раздел «Мои заявки». Ник тот же, что указан в заявке. Закрытая заявка пропадает из общего списка.

## Переписки

Адрес: https://pes-kompas.vercel.app/admin

Пароль: `peskompas`. Его можно сменить строкой `ADMIN_PASSWORD` в файле `.env`.

С главной страницы и из бота ссылки туда нет. В поиске вводится номер заявки, открывается её переписка. Видны заявки, созданные на этом же сайте.

## Локальный запуск

Нужен Python 3. В папке проекта:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Сайт на компьютере: http://127.0.0.1:8080

Бот, второе окно терминала:

```bash
source venv/bin/activate
python bot.py
```

Токен бота выдаёт @BotFather и записывается в `.env`. Туда же кладётся `SITE_URL` — адрес, который бот открывает кнопкой. Файл `.env` и база `data/kompas.sqlite3` в репозиторий не входят. База на компьютере создаётся сама при первом запуске.
